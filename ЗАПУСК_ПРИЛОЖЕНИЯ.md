# 🚀 Инструкция по запуску приложения "Менеджер Строительства"

## 📋 Системные требования

### Для разработки:
- **Android Studio** Hedgehog или новее (рекомендуется Meerkat Feature Drop)
- **JDK 17** или новее
- **Android SDK** с API 34
- **Gradle 8.2+**
- Минимум **4 ГБ RAM** для Android Studio

### Для устройства/эмулятора:
- **Android 8.0** (API 26) или новее
- **2 ГБ RAM** минимум, 4 ГБ рекомендуется
- **100 МБ** свободного места

## 🛠️ Пошаговая инструкция запуска

### 1. Открытие проекта
```bash
1. Запустите Android Studio
2. Выберите "Open an Existing Project"
3. Укажите папку с проектом (где находится build.gradle.kts)
4. Дождитесь синхронизации Gradle (может занять 5-10 минут)
```

### 2. Настройка эмулятора (если нужно)
```bash
1. Tools → AVD Manager
2. Create Virtual Device
3. Выберите Pixel 6 или любое устройство с API 26+
4. Скачайте системный образ Android 8.0+ если нужно
5. Запустите эмулятор
```

### 3. Запуск приложения
```bash
1. Убедитесь, что эмулятор запущен или устройство подключено
2. Нажмите кнопку "Run" (зеленый треугольник) или Shift+F10
3. Выберите устройство для запуска
4. Дождитесь компиляции и установки (первый раз может занять 3-5 минут)
```

## 🐛 Возможные проблемы и решения

### Проблема: "Gradle sync failed"
**Решение:**
```bash
1. File → Invalidate Caches and Restart
2. Убедитесь, что у вас установлен JDK 17
3. Проверьте интернет-соединение
4. Попробуйте Tools → Android → Sync Project with Gradle Files
```

### Проблема: "App crashes on startup"
**Решение:**
```bash
1. Проверьте логи в Logcat
2. Убедитесь, что эмулятор имеет API 26+
3. Попробуйте Build → Clean Project, затем Rebuild Project
4. Перезапустите эмулятор
```

### Проблема: "No connected devices"
**Решение:**
```bash
1. Для эмулятора: убедитесь, что AVD запущен
2. Для устройства: включите "Отладка по USB" в настройках разработчика
3. Проверьте, что устройство отображается в "adb devices"
```

## 📱 Тестирование экспорта

### PDF экспорт:
1. Войдите как admin или manager
2. Перейдите в раздел "Сметы"
3. Нажмите "Экспорт PDF" на любой смете
4. Файл сохранится в Downloads устройства

### CSV экспорт:
1. Аналогично PDF
2. Нажмите "Экспорт CSV"
3. Файл можно открыть в Excel, Google Sheets или любом текстовом редакторе
