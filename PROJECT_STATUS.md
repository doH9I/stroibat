## 🔗 API Endpoints

### Аутентификация
- `POST /api/v1/auth/login` - Вход в систему
- `GET /api/v1/auth/me` - Информация о пользователе
- `POST /api/v1/auth/register` - Регистрация
- `POST /api/v1/auth/change-password` - Смена пароля

### Проекты
- `GET /api/v1/projects` - Список проектов
- `GET /api/v1/projects/{id}` - Конкретный проект
- `POST /api/v1/projects` - Создание проекта
- `PUT /api/v1/projects/{id}` - Обновление проекта
- `DELETE /api/v1/projects/{id}` - Удаление проекта

### Клиенты
- `GET /api/v1/clients` - Список клиентов
- `GET /api/v1/clients/{id}` - Конкретный клиент
- `POST /api/v1/clients` - Создание клиента
- `PUT /api/v1/clients/{id}` - Обновление клиента
- `DELETE /api/v1/clients/{id}` - Удаление клиента

### Служебные
- `GET /health` - Проверка здоровья системы
- `GET /docs` - API документация
- `GET /redoc` - Альтернативная документация

## 🚀 Способы запуска

### 1. Docker (Рекомендуется)
```bash
docker-compose up -d
# Frontend: http://localhost
# API: http://localhost:8000
# Docs: http://localhost:8000/docs
```

### 2. Локальная разработка
```bash
# Backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python init_db.py
python run.py

# Frontend - откройте public/index.html в браузере
```

### 3. Netlify + внешний API
- Frontend развертывается на Netlify
- Backend развертывается на Heroku/Railway/DigitalOcean
