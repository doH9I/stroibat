## 🚀 **Как пользоваться:**

### 1. **Запуск:**
```bash
python3 -m http.server 8000
```

### 2. **Авторизация:**
- Откройте `http://localhost:8000/`
- Введите: `admin@buildcrm.com` / `admin123`
- Система перенаправит на дашборд

### 3. **Навигация:**
- Используйте боковую панель для перехода между разделами
- Каждый раздел - отдельная HTML страница
- Все кнопки и функции работают

### 4. **Основные функции:**
- **Проекты**: создание, редактирование, фильтрация, поиск
- **Сотрудники**: полное управление персоналом
- **Табель**: учет времени с таймером и отчетами
- **Настройки**: 5 вкладок с различными опциями
- **Дашборд**: интерактивные графики и статистика
