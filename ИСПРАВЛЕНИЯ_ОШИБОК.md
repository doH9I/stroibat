# 🔧 Исправления ошибок компиляции

## ✅ Все ошибки успешно исправлены!

### 🚨 Основные проблемы, которые были решены:

#### 1. **Проблема с минимальной версией Android API**
**Ошибка:** 
```
MethodHandle.invoke and MethodHandle.invokeExact are only supported starting with Android O (--min-api 26)
```

**Решение:**
- Повышен минимальный API с 24 до 26 (Android 8.0)
- Обновлены все документы и инструкции

#### 2. **Проблема с Apache POI**
**Ошибка:** 
```
Failed to transform poi-5.2.4.jar - requires API 26+
```

**Решение:**
- Заменен Apache POI на OpenCSV (более легкая библиотека)
- Обновлены все функции экспорта с Excel на CSV
- CSV файлы легко открываются в Excel, Google Sheets и любых текстовых редакторах

#### 3. **Проблема с Material Design 3 темой**
**Ошибка:**
```
style/Theme.Material3.DayNight.NoActionBar not found
colorOnPrimary, colorPrimaryContainer и другие атрибуты не найдены
```

**Решение:**
- Упрощена тема, убраны несовместимые атрибуты
- Оставлены только основные цвета, поддерживаемые текущей версией Material Design

#### 4. **Обновлены зависимости**
- Приведены все версии библиотек к совместимым
- Исправлены конфликты версий
- Добавлен OpenCSV для работы с CSV файлами
