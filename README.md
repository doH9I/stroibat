# Менеджер Строительства

Комплексное мобильное приложение для управления строительными проектами на Android.

## Описание

Полнофункциональное приложение для управления строительными проектами с современным дизайном в стиле iOS и всеми необходимыми возможностями для эффективной работы строительных компаний.

## Основные возможности

### 🏗️ Управление проектами
- Создание и ведение проектов
- Планирование этапов работ
- Контроль бюджета и сроков
- Координаты и адреса объектов

### 💰 Модуль составления смет
- Автоматический расчет сумм с НДС и без НДС
- База видов работ с единицами измерения и базовыми ценами
- Настраиваемые надбавки и непредвиденные расходы
- Категории работ: земляные, фундамент, стены, кровля, отделка
- **Экспорт смет в PDF и Excel** ✅

### 👥 Система ролей и доступа
- Администратор - полный доступ ко всем функциям
- Генеральный директор - стратегическое управление и аналитика
- Директор по строительству - операционное управление проектами
- Финансовый директор - контроль бюджетов и расходов
- Руководитель проекта - управление конкретными проектами
- И другие роли...

### 📊 Функциональные модули
- **Панель управления** с аналитикой и быстрыми действиями
- **Система отчетности** с настраиваемыми шаблонами
- **Фото фиксация** с геотегами и временными метками
- **Управление замечаниями** с фиксацией дефектов
- **Заказ материалов и инструментов**
- **Табель учета времени**
- **Уведомления и напоминания**

### 🏢 Управление организациями
- Реквизиты компании
- База заказчиков с типами и условиями оплаты
- Подрядчики с рейтингами и специализациями
- Автоматическое заполнение документов реквизитами

## Техническая архитектура

### 💻 Технологический стек
- **Язык:** Kotlin 100%
- **UI Framework:** Jetpack Compose
- **Архитектура:** MVVM + Clean Architecture
- **База данных:** Room Database (12 основных таблиц)
- **DI:** Hilt (Dagger)
- **Асинхронность:** Coroutines + Flow
- **Навигация:** Navigation Compose
- **HTTP:** Retrofit + OkHttp
- **Изображения:** Coil
- **Экспорт:** iTextPDF + Apache POI

### 🗃️ База данных
- 12 основных таблиц для всех сущностей системы
- Связанные данные с foreign key constraints
- Type converters для сложных типов данных
- Миграции для обновления схемы
- Индексы для оптимизации запросов

### 🔐 Безопасность
- Хеширование паролей SHA-256 с солью
- Ролевая система с детальными разрешениями
- Сессии пользователей с автоматическим выходом
- Шифрование чувствительных данных

### 🎨 Дизайн и UX
- Material Design 3 с современными компонентами
- Темная и светлая темы
- Адаптивный интерфейс для разных размеров экранов
- Плавные анимации и переходы
- Интуитивная навигация в стиле iOS

## Установка и запуск

1. Клонируйте репозиторий
2. Откройте проект в Android Studio Meerkat Feature Drop
3. Синхронизируйте проект с Gradle файлами
4. Запустите приложение на эмуляторе или устройстве

## Архитектурные особенности

### Clean Architecture
```
app/
├── data/           # Слой данных
│   ├── entities/   # Сущности базы данных
│   ├── dao/        # Data Access Objects
│   ├── repository/ # Репозитории
│   └── database/   # Конфигурация базы данных
├── di/             # Dependency Injection
├── ui/             # Пользовательский интерфейс
│   ├── screens/    # Экраны приложения
│   └── theme/      # Тема и стили
├── utils/          # Утилиты
└── navigation/     # Навигация
```

### MVVM Pattern
- **Model:** Сущности и репозитории
- **View:** Composable функции
- **ViewModel:** Бизнес-логика и состояние UI
