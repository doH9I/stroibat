# Construction Management App

**Construction Management App** — это комплексное мобильное приложение для управления строительными проектами, разработанное на Kotlin с использованием Jetpack Compose и Material Design 3. Приложение предназначено для профессионального использования в строительных компаниях, подрядных организациях и службах заказчика.

## Основные возможности

- **Административная панель**: управление пользователями, ролями, организациями, аналитика и мониторинг активности.
- **Ролевая система**: гибкая настройка прав доступа для всех типов сотрудников (от администратора до рабочего).
- **Управление проектами**: создание, планирование, контроль бюджета, сроков, координат объектов.
- **Сметы**: автоматический расчет с НДС/без НДС, база работ, надбавки, экспорт в PDF и Excel.
- **Интеграция с магазинами**: API для Леман, Петрович, универсальный API для других поставщиков.
- **Управление организациями**: реквизиты, заказчики, подрядчики, автоматизация документов.
- **Система отчетности**: шаблоны, ежедневные отчеты, фотофиксация, интеграция с исполнительной документацией.
- **Фотофиксация**: привязка фото к объектам, этапам, геотеги, альбомы.
- **Управление замечаниями**: фиксация дефектов, контроль устранения.
- **Заказ материалов**: интеграция с каталогами, заявки, отслеживание поставок, склад.
- **Табель учета времени**: учет рабочего времени, смены, переработки.
- **Уведомления**: push, напоминания, календарь событий, эскалация задач.
- **Аналитика и отчеты**: статистика пользователей, проектов, дефектов, затрат, времени, экспорт в PDF/Excel.
- **Корпоративные функции**: мультипроектность, интеграция с 1С, резервное копирование, офлайн режим, облако.
- **Безопасность**: SHA-256 с солью, шифрование, сессии, автоматический выход.
- **Дизайн**: современный Material 3, темная/светлая тема, плавные анимации, адаптивность.

## Технологии

- **Kotlin**
- **Jetpack Compose**
- **Room (32+ таблицы, миграции, индексы, конвертеры)**
- **Hilt (DI)**
- **Retrofit (API)**
- **iText PDF, Apache POI (экспорт PDF/Excel)**
- **MPAndroidChart (графики)**
- **CameraX, Coil (фотофиксация)**
- **Google Play Services (геолокация, уведомления)**
- **Accompanist (разрешения)**

## Сборка и запуск

1. Откройте проект в **Android Studio Meerkat Feature Drop**.
2. Установите все зависимости (Gradle sync).
3. Соберите и запустите приложение на устройстве или эмуляторе (minSdk 24, targetSdk 34).
4. Для работы с API и интеграциями настройте соответствующие ключи и параметры в `local.properties` или через BuildConfig.

## Структура проекта

- `app/src/main/java/com/construction/management/` — основной код приложения
  - `data/model` — модели данных (пользователи, проекты, сметы, отчеты и др.)
  - `data/database` — база данных Room, DAO, конвертеры
  - `data/repository` — репозитории
  - `ui/theme` — тема, цвета, типографика
  - `ui/navigation` — навигация
  - `ui/screens` — экраны приложения
  - `ui/viewmodel` — ViewModel для управления состоянием

## Экспорт отчетов

- Экспорт в **PDF** и **Excel** доступен из соответствующих экранов (сметы, отчеты).
- Шаблоны документов уже реализованы и готовы к использованию.

## Безопасность

- Пароли хранятся с хешированием SHA-256 + соль.
- Все чувствительные данные шифруются.
- Сессии пользователей с автоматическим выходом.
