# BuildCRM - Система управления строительными проектами

Современная веб-система CRM для строительных компаний, разработанная с использованием HTML5, JavaScript и CSS. Система предоставляет полный набор инструментов для управления проектами, сотрудниками, сметами и аналитики.

## 🚀 Возможности

### Основные модули:
- **Дашборд** - Аналитика и ключевые показатели
- **Проекты** - Управление строительными проектами
- **Сметы** - Создание и управление сметами
- **Сотрудники** - Управление персоналом
- **Табель** - Учет рабочего времени
- **Аналитика** - Детальная аналитика и графики
- **Календарь** - Планирование и события
- **Отчеты** - Генерация различных отчетов
- **Настройки** - Конфигурация системы

### Ключевые функции:
- ✅ Полностью функциональная система без заглушек
- ✅ Современный адаптивный дизайн
- ✅ Интерактивные графики и диаграммы
- ✅ Система уведомлений
- ✅ Модальные окна для форм
- ✅ Экспорт данных в CSV/Excel
- ✅ Поиск по всем модулям
- ✅ Аутентификация пользователей
- ✅ Responsive дизайн для мобильных устройств

## 🛠 Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Стилизация**: Custom CSS с Flexbox и Grid
- **Графики**: Chart.js
- **Иконки**: Font Awesome 6
- **Шрифты**: Google Fonts (Inter)
- **Хранение данных**: localStorage (для демо)

## 📦 Установка и запуск

### Локальный запуск:

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd buildcrm
```

2. Откройте `index.html` в браузере или запустите локальный сервер:
```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен)
npx serve .

# PHP
php -S localhost:8000
```

3. Откройте браузер и перейдите по адресу: `http://localhost:8000`

### Демо доступ:
- **Email**: admin@buildcrm.com
- **Пароль**: admin123

## 🌐 Развертывание на Netlify

### Автоматическое развертывание:

1. Создайте аккаунт на [Netlify](https://netlify.com)
2. Подключите ваш GitHub репозиторий
3. Настройте параметры развертывания:
   - **Build command**: оставьте пустым
   - **Publish directory**: `.` (корневая папка)
4. Нажмите "Deploy site"

### Ручное развертывание:

1. Создайте аккаунт на Netlify
2. Перетащите папку с проектом в область развертывания
3. Дождитесь завершения развертывания

### Настройка домена:
- В настройках сайта на Netlify можно настроить кастомный домен
- Доступен бесплатный SSL сертификат

## 🔧 Конфигурация

### Настройка данных:
- Все демо данные находятся в файле `js/app.js`
- Для подключения к реальному API измените метод `loadData()` в `js/app.js`

### Настройка уведомлений:
- Email уведомления настраиваются в модуле настроек
- SMS уведомления требуют интеграции с SMS-сервисом

### Настройка интеграций:
- Календарь: интеграция с Google Calendar
- Email: интеграция с SMTP сервером
- Файловое хранилище: локальное или облачное
