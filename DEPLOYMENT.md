# Инструкции по развертыванию BuildCRM

## 🚀 Быстрый старт

### 1. Локальное тестирование

```bash
# Запуск локального сервера
python3 -m http.server 8000

# Или с помощью Node.js
npx serve .

# Или с помощью PHP
php -S localhost:8000
```

Откройте браузер: `http://localhost:8000`

- **Email**: admin@buildcrm.com
- **Пароль**: admin123

## 🌐 Развертывание на Netlify

### Способ 1: Drag & Drop (Самый простой)

1. Перейдите на [netlify.com](https://netlify.com)
2. Создайте аккаунт или войдите
3. Перетащите всю папку проекта в область "Drag and drop your site output folder here"
4. Дождитесь завершения развертывания
5. Получите URL вида: `https://random-name.netlify.app`

### Способ 2: Через Git (Рекомендуемый)

1. Загрузите проект на GitHub/GitLab/Bitbucket
2. Войдите в Netlify
3. Нажмите "New site from Git"
4. Выберите ваш репозиторий
5. Настройте параметры:
   - **Build command**: оставьте пустым
   - **Publish directory**: `.` (точка)
6. Нажмите "Deploy site"

### Способ 3: Через Netlify CLI

```bash
# Установка CLI
npm install -g netlify-cli

# Вход в аккаунт
netlify login

# Инициализация проекта
netlify init

# Развертывание
netlify deploy --prod
```

## ⚙️ Настройка после развертывания

### 1. Кастомный домен

1. В настройках сайта на Netlify перейдите в "Domain settings"
2. Нажмите "Add custom domain"
3. Введите ваш домен
4. Настройте DNS записи согласно инструкциям

### 2. SSL сертификат

- Netlify автоматически предоставляет бесплатный SSL сертификат
- Активируется через несколько минут после добавления домена

### 3. Переменные окружения (если понадобятся)

В настройках сайта → Environment variables:
```
API_URL=https://your-api.com
ENVIRONMENT=production
```

## 🔧 Конфигурация для продакшена

### 1. Оптимизация производительности

```bash
# Минификация CSS (если нужно)
npm install -g clean-css-cli
cleancss -o styles/main.min.css styles/main.css

# Минификация JS (если нужно)
npm install -g uglify-js
uglifyjs js/app.js -o js/app.min.js
```

### 2. Настройка кэширования

Файл `netlify.toml` уже настроен для оптимального кэширования:
- CSS/JS файлы: 1 год
- Изображения: 1 год
- HTML файлы: без кэширования

### 3. Безопасность

Заголовки безопасности уже настроены в `netlify.toml`:
- X-Frame-Options: DENY
- X-XSS-Protection: 1; mode=block
- X-Content-Type-Options: nosniff

## 🐛 Устранение проблем

### Проблема: Сайт не загружается
**Решение:**
1. Проверьте, что все файлы загружены
2. Убедитесь, что `index.html` в корневой папке
3. Проверьте консоль браузера на ошибки

### Проблема: Графики не отображаются
**Решение:**
1. Проверьте подключение к интернету (Chart.js загружается с CDN)
2. Проверьте консоль на ошибки JavaScript

### Проблема: Данные не сохраняются
**Решение:**
1. Проверьте, что localStorage доступен
2. Проверьте настройки приватности браузера

### Проблема: Мобильная версия не работает
**Решение:**
1. Проверьте viewport meta тег в `index.html`
2. Убедитесь, что CSS медиа-запросы работают

### Google Analytics (бесплатно)
Добавьте в `index.html`:
```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_MEASUREMENT_ID');
</script>
```
